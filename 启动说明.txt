========================================================
 视频地图 · 换机器演示说明
========================================================

一、这一包里有什么
   Code\project_geojson_preview.html   主页面（演示入口）
   Code\project_manager.py             后端
   Code\project_manager.html 等        早期页面（不影响演示）
   Code\tianditu_key.txt               天地图底图密钥
                                       ★ 演示必需；但绝不能提交到 GitHub ★

二、新电脑上还需要什么
   1. Python 3.10+        —— 必需，后端靠它跑
   2. FFmpeg              —— 可选。只有当 SRT / GeoJSON 需要现场生成时才要；
                             如果数据文件夹里已经有 .srt 和 .geojson，可以不装
   3. 浏览器（Chrome / Edge）—— 必需，演示就在浏览器里

三、数据怎么放（关键）
   把【整个数据文件夹】拷过来，不要只拷 MP4：
       数据文件夹\
         DJI_xxx_V.MP4 / _S.MP4 / _T.MP4    视频
         DJI_xxx_V.srt / _S.srt / _T.srt    遥测字幕（生成轨迹要用）
         DJI_xxx_V.geojson 等               已生成的轨迹（有它演示才秒开）
   只拷 MP4 也能用，但每次导入都要现场抽字幕、生成轨迹，演示会卡很久。

四、新电脑上怎么起
   1. 把 Code\ 放在任意目录，例如 D:\视频地图\Code
   2. 打开终端（PowerShell 或 cmd），执行：
          cd D:\视频地图\Code
          python -B project_manager.py
      看到它打印监听信息就是起来了（固定用 127.0.0.1:8000）
   3. 浏览器打开：
          http://127.0.0.1:8000/project_geojson_preview.html

五、演示前做一次（务必）
   1. 左栏「新建项目」→ 填个名字 → 在弹出的框里选数据文件夹
   2. 等自动流程跑完（检测字幕 → 生成 SRT → 生成 GeoJSON → 加载到地图）
      —— 如果数据里已有 .srt/.geojson，这一步几乎瞬间完成
   3. 点「加载全部」→ 地图上出现航迹
   4. 地图上点轨迹 → 气泡里点「从点击位置播放」→ 右侧出视频
      ← 这就是演示的核心：地图点哪，视频就播哪
   6. 建议先关掉不需要的终端窗口，避免演示时被弹窗打断

六、常见问题
   · 底图空白          → Code\tianditu_key.txt 没拷过来；或改用「OpenStreetMap」
   · 端口被占用        → 关掉已在跑的那个后端进程
   · 文件列表是空的    → 「刷新」一下；仍空就检查项目里有没有导入数据文件夹
   · 提示缺 SRT/GeoJSON → 点「生成 SRT」「生成 GeoJSON」（需要 FFmpeg）
