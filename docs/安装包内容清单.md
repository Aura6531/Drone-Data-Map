# 安装包里到底装了什么 —— 内容清单与用途

> 已确定的交付方式：**安装包（Inno Setup）**；**天地图 key 在安装结束页让使用者自己填**（附链接与说明）；
> **数据放在程序目录内**；**关闭方式用托盘图标**。
> 本文只是清单与设计说明，还没开始动手。体积是实测值。

---

## A. 程序本体（我们自己的代码与页面）

| 文件 | 来源 | 大小 | 作用 |
|---|---|---|---|
| `Code\project_manager.py` | 仓库 | ~250KB | **后端全部逻辑**：本地 HTTP 服务、SRT 遥测解析、ffmpeg 调用（抽帧/转码）、地图瓦片代理与缓存、天地图逆地理编码、Word 报告生成（Pillow 画图 + python-docx 排版）、项目与标记点读写 |
| `Code\project_geojson_preview.html` | 仓库 | 222KB | **主界面**（单文件）：地图、视频播放、标记点列表与批量操作、报告弹窗、底图切换。所有前端逻辑都在这里面 |
| `Code\project_manager.html` | 仓库 | 15KB | 旧版「项目管理」页，仍在导航菜单里 → 要带（不带会 404） |
| `Code\project_import.html` | 仓库 | 42KB | 导入数据的独立页（备用入口） |
| `Code\project_media.html` | 仓库 | 23KB | 媒体/文件管理页 |
| `Code\project_geo3d_preview.html` | 仓库 | 31KB | 3D 轨迹预览页（当前 3D 功能搁置，但页面与路由还在） |
| `Code\project_video_inspector.html` | 仓库 | 32KB | 视频/字幕检查工具页（开发排查用） |
| `vendor\leaflet.js` + `vendor\leaflet.css` | **需要新增**（现在仓库里没有，页面靠 CDN） | ~180KB | 前端地图库。**必须随包**，否则断网/内网打开页面直接白屏 |
| `UAVMap.ico` | **需要新做** | ~50KB | 程序图标：exe、开始菜单快捷方式、桌面快捷方式、**托盘图标**都用它 |
| `使用说明.pdf`（或 html） | **需要新写** | ~0.5MB | 给使用者的说明书（开发文档不适合给外人看） |

> 6 个页面加起来 ~365KB，**不值得为省这点体积去裁剪**（少一个就多一个 404 风险）。

## B. Python 运行时与第三方库（PyInstaller 自动收集，无需手工放）

| 组件 | 大小 | 作用 |
|---|---|---|
| Python 3.14 运行时（`python314.dll` + 必需标准库） | ~25–35MB | 让 exe 在没有装 Python 的电脑上也能跑。我们只用标准库的 HTTP 服务、JSON、urllib、subprocess、threading 等 |
| Pillow 12.3.0（含 `_imaging` 等扩展模块） | 15.5MB | 地图拼瓦片、在图上画红十字/飞机箭头/注视虚线/目标点标志、JPEG 落盘、读图片尺寸算报告版面 |
| python-docx 1.2.0 + 自带模板 `default.docx` | 2.3MB | 生成 Word 报告（**模板文件必须被收集**，否则一生成就报错） |
| lxml 6.1.2（含 `etree` 扩展） | 8.9MB | python-docx 的底层 XML 库（做书签 + 可点击目录要用） |
| Tcl/Tk（`tcl86t.dll`、`tk86t.dll`、`tcl\` 目录） | ~5MB | 「导入数据」里**选择文件夹 / 选择文件**的系统对话框（`filedialog`）—— 后端确实在用 |
| `ctypes`（标准库，无额外文件） | — | 调 Windows API 设置 DPI 感知，避免高分屏下界面发虚 |

**不打包**：numpy、requests（环境里装了但代码没用到）、pip/setuptools、测试框架。

## C. ffmpeg（体积大头）

| 文件 | 大小 | 作用 |
|---|---|---|
| `ffmpeg\ffmpeg.exe` | **~70–90MB** | 两件事：① 从**原片**抽一帧做 Word 报告的视频截图（原始分辨率）② 把 4K HEVC 按需转成 H.264 片段（网页播放代理）—— Chrome/Edge 在 Windows 上不能软解 HEVC，Firefox 完全不支持，**没有它 4K 视频就播不了** |
| ~~`ffprobe.exe`~~ | 省掉 ~40–90MB | **实测代码里没有真正调用它**（只拿它来推断 ffmpeg 的位置）。给 `find_ffmpeg()` 加上"先找同目录 ffmpeg.exe"之后就不需要它了。以后真要用再补 |
| `LICENSE-ffmpeg.txt` + 来源说明 | ~35KB | 用的是 GPLv3 构建（含 x264/x265），分发必须附许可与来源（[gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 的 essentials 构建：7z 34MB，解包后只取 ffmpeg.exe） |

## D. 安装器自身（Inno Setup 生成的 setup.exe）

| 内容 | 作用 |
|---|---|
| 安装向导（选择安装目录、确认、进度、完成） | 一般用户熟悉的流程 |
| **结束页的天地图 key 输入框** | 让使用者粘自己的 tk，附**申请链接**与三步说明（注册 → 控制台创建「浏览器端」key → 粘贴）。写入 `程序目录\tianditu_key.txt`（程序支持改完不重启） |
| 结束页「申请天地图 key」的说明/按钮 | 用系统浏览器打开天地图控制台地址 |
| 开始菜单快捷方式 + 桌面快捷方式（可选勾选） | 双击即启动 |
| 卸载项（控制面板「程序和功能」） | 可正常卸载；**卸载时保留 `Data\` `Project\`**（用户数据不能删） |
| 版本信息、发布者、图标 | 显示在安装包属性和「程序和功能」里 |
| 第三方许可文本合集 | Python(PSF)、Pillow、python-docx(MIT)、lxml(BSD)、Leaflet(BSD-2)、ffmpeg(GPLv3) —— 合规用 |

**安装目录默认值**：`%LOCALAPPDATA%\无人机巡查数据地图`（**不要默认 Program Files** —— 写不进 Data/Project）。
如果使用者非要装到 Program Files，程序启动时检测不可写 → 给明确提示（或自动把数据落到 `%LOCALAPPDATA%`）。

## E. 安装后自动生成、但**不在安装包里**的目录（要跟使用者讲清楚）

| 目录 | 内容 | 说明 |
|---|---|---|
| `Data\` | 导入的视频、SRT、GeoJSON | 使用者自己的数据；换机器要重新导入 |
| `Project\<项目名>\project.json` | 项目定义 + 标记点 | 删项目 ≠ 删数据（只删这一层） |
| `tile_cache\` | 地图瓦片缓存 | 越用越快、省流量；可随时删 |
| `video_proxy\` | 转码片段缓存 | 上限 4GB，超出自动删最旧的；可随时删 |
| `report_cache\` | 抽帧图与生成的 Word | 报告产物；可随时删 |
| `Code\geocode_cache\` | 逆地理编码结果 | 30 天有效；可随时删 |
| `tianditu_key.txt` | 天地图 key | 安装结束页写入，或首次运行时用记事本填 |

## F. 明确**不**放进安装包的东西

| 排除项 | 原因 |
|---|---|
| `test_*.js` / `check_*.py` / `run_tests.js` | 开发测试，与使用者无关 |
| `docs\`（交接说明、打包分析、需求文档） | 开发文档；给使用者的另写《使用说明》 |
| `media\`（几张 3~4MB 的截图） | 文档配图，不进包 |
| `lens_probe\` / `_demo*` / `_backup\` / `_migration\` | 临时与备份目录 |
| 你机器上的 Python、ffmpeg 安装 | 只带必需部分（见 B、C） |
| `Data\`、`Project\`、各种 cache | 使用者自己的数据，不随包 |
| numpy / requests / pip 等 | 代码没用到 |

## 使用者会经历的完整流程（装完是什么样）

1. 双击 `无人机巡查数据地图_安装程序.exe` → 选目录（默认 `%LOCALAPPDATA%\无人机巡查数据地图`）→ 下一步
2. **结束页**：粘天地图 key（旁边有「怎么申请」的链接与三步说明；也可以先跳过，之后用记事本填）
3. 勾选「立即启动」→ 程序**常驻托盘**（右下角小飞机图标）并自动用 Edge 以应用窗口模式打开界面
4. 进去以后：新建项目 → 导入数据（选文件夹/选文件）→ 加载轨迹 → 点地图定位 → 右键取点命名 → 生成 Word 报告
5. 退出：右键托盘图标 →「退出」；或在托盘菜单里「重启服务」「打开界面」「打开数据目录」
