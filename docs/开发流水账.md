## 这份东西能证明什么、不能证明什么

**能证明**

- 需求到实现的**完整闭环**：每个提交都带原因，能看出从「用户一句话」到「代码怎么改」的对应关系
- **返工与推翻是常态**：`revert` 出现过多次（默认底图改卫星又改回街道、
  天地图申请指南 PDF 加了又去掉），说明是边做边判断，不是想好再写
- **细节是靠实测逼出来的**：例如「表格边框比照片多出 2mm」是用户在 Word 里量出来的，
  根因是单元格默认边距，改成 0 才对齐

**不能证明 / 要如实说的**

- **不是逐字的完整提示词记录**：10-06、10-07 两天的原话在另一台电脑的会话里
- 提交是**聚合后**的记录：一个提交可能对应对话里来回好几轮
- 10-12 的会话记录是这台笔记本上的，**仅覆盖演示与开源这一段**
