## 一、这是什么

把 DJI 无人机的飞行遥测与视频对齐的**本地工具**：点地图上任意位置，
就能跳到那一刻、那个位置拍的画面。核心卖点是**地图 ↔ 视频同步**。

- 前端：`Code/project_geojson_preview.html`（单文件，界面与逻辑都在这）
- 后端：`Code/project_manager.py`（HTTP 服务 + SRT 解析 + ffmpeg 调用）
- 测试：仓库根目录 `test_*.js` / `check_page.js` / `check_py.py` / `test_geocode.py`
- 数据：`Data/`（不进仓库）；项目定义：`Project/`（本地状态，不进仓库）

## 二、跑起来

```bash
cd Code
python -B project_manager.py        # 固定绑定 127.0.0.1:8000
# 浏览器打开 http://127.0.0.1:8000/project_geojson_preview.html
```

**依赖**：Python 3.10+（必需）、FFmpeg（抽字幕流/转码才需要）、天地图 key
（`Code/tianditu_key.txt`，**不进仓库**，缺失时底图可切 OpenStreetMap）。

**Windows 沙箱注意**：如果后端写入 `Code/`、`Project/`、`Data/` 时报
`PermissionError [WinError 5]`，说明启动它的进程没有这几个目录的写权限 ——
需要以完全权限启动（这些目录缺少沙箱的继承授权 ACE）。
仓库里带了一个诊断技能：`diagnose-windows-sandbox-acl`。

## 三、必须先知道的约定（违反就会出问题）

1. **只处理 DJI 标准命名**：`DJI_YYYYMMDDHHMMSS_NNNN_X`（`_V`/`_S` 可见光、`_T` 热成像）。
2. **GeoJSON 的要素级 `properties` 必须含 `point_times`** —— 地图检索、视频跳转、
   飞机箭头同步全部依赖它。缺了就"点得到、跳不准"。
3. **`generate_geojson_for_video` 读的是同名 `.srt` 文件**，不依赖 MP4 里是否还有字幕流。
   所以剪辑过的素材只要把同名 `.srt` 放回去，就仍能生成轨迹。
4. **高度是相对起飞点**；相机视场框与「画面取点」都基于**平地假设** ——
   俯角大（近处）准，接近平视会明显偏（实测 1° 俯仰误差 ≈ 112 m）。
5. **删除项目 ≠ 删除数据**：只移除 `Project/<名字>/`，`Data/` 一律不动。
   文件列表里的「删除」只删该视频对应的 GeoJSON（含 3D 版）与 SRT，**绝不碰 MP4**。
6. **SRT 遥测字段**（`/api/project/telemetry` 提供，按视频）：`times/alt/yaw/pitch/focal/dzoom`。

## 四、检索「A+B」是怎么工作的（最近一次主要改动）

用户点地图某点后，不再只找"无人机离它最近"，而是：

```
B（筛）把目标点反投影回图像 → (xImg,yImg) ∈ [-1,1] 即"这一帧看得见"
A（排）在看得见的帧里，按"该帧画面中心点到目标的地面距离"取最近
回退   pitch>=0 打不到地面 → 不参与判定
       focal 缺失 → 用广角基准 BASE_FOCAL=24mm
       全部不可见 → 退回"无人机位置最近"，并在结果里标 inFrame=false
```

- 数学：`frameCenterLatLng()`（正投影，复用 `groundPointForImage`）
  与 `imagePointOfGround()`（反投影）**严格互逆** —— 由 `test_ab.js` 保证
  （往返误差 ~1e-12）。改这两处务必先跑它。
- 遥测来源：检索要跨所有已加载航迹，所以按视频预取并缓存
  （`telemetryByPath` + 挂在航迹对象上的 `t.telemetry`，供同步读取）。
- 预取未完成时会先给回退结果，**300ms 后自动重搜一次**（`scheduleResearchAfterPrefetch`）。

## 五、全屏

**只有一条路**：`<video>` 自带控件里那个全屏按钮 —— 浏览器把 video 单独全屏，
外面的浮层由 `fullscreenchange` 给对话框加 `native-fs` 类隐藏
（标题栏/小地图/红外/信息行）。真铺满、零黑边。

曾经的「对话框铺满（theater）」那套（含自制全屏按钮）**已整体删除**，
不要再加回来 —— 它在全屏下始终有黑边，且容易和原生全屏打架。

## 七、当前待办 / 已知项

- **SRT 多机型兼容**：目前只认 M4T/M3E 这一种格式。参考
  [dji-drone-metadata-embedder](https://github.com/CallMarcus/dji-drone-metadata-embedder)
  的 `docs/SRT_FORMATS.md`（十余种机型的正则目录）做格式探测 —— 评估为"最该做的一项"。
- 4 GB 分段录像（DJI 长航时会在 4GB 处切文件）目前按单个视频处理。
- 「标记此处」的点**不持久化**（刷新即清、点「清空」一起清）—— 是产品决定。
