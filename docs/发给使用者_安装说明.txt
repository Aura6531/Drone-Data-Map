无人机巡查数据地图 —— 安装说明（先看这个）
================================================

一、这个压缩包里有什么
   无人机巡查数据地图_安装程序.exe   安装程序，双击它
   _internal\                        安装程序的运行时与程序载荷（别删、别单独拷走）
   安装说明（先看这个）.txt           本文件

二、第一次运行会被 Windows 拦一下 —— 正常现象，不是病毒
   Windows 会弹「Windows 已保护你的电脑 / Microsoft Defender SmartScreen 阻止了
   无法识别的应用」（Application: 无人机巡查数据地图_安装程序.exe，
   Publisher: Unknown publisher）。

   原因只有一个：这个程序没有购买代码签名证书。Windows 对「没有签名、又没有下载量
   记录」的程序一律这样提示，和程序做什么、干不干净无关。

   怎么继续（任选一种）：
     1) 弹窗里如果有「更多信息」，先点它，再点「仍要运行」；
        如果像本机这样直接是两个按钮，就点「仍要运行 / Run anyway」。
     2) 或者：右键 exe → 属性 → 勾选底部的「解除锁定」→ 确定，然后再双击。
     3) 公司电脑若被策略禁用了 SmartScreen，找管理员放行。

   装完可以自己核对：程序只写在 %LOCALAPPDATA%\无人机巡查数据地图 这一个目录里，
   卸载时清干净（你的数据会保留，见第五节）。

三、安装
   1) 双击 无人机巡查数据地图_安装程序.exe
   2) 选安装位置：默认 %LOCALAPPDATA%\无人机巡查数据地图，建议就用默认。
      * 不要装到 Program Files —— 程序会把导入的视频、标记点存在安装目录里，
        装到系统目录会因为没写权限而出问题。
   3) 填「天地图 key」（可以跳过）：
        申请地址：https://lbs.tianditu.gov.cn/authorization/authorization.html
          ① 打开网址注册 / 登录
          ② 创建应用，应用类型选「浏览器端」
          ③ 把生成的 32 位 tk 复制过来
        不填也能用：底图自动退回 OpenStreetMap，只是地名搜索不可用。
        以后想补：把 tk 存成 <安装目录>\tianditu_key.txt，存盘就生效，不用重装。
   4) 勾选要不要桌面快捷方式、装完是否立即启动（**不会开机自启**）。

四、使用
   * 界面用系统自带的 Edge / Chrome 打开，不需要额外装浏览器。
   * 程序常驻右下角托盘图标：
       双击 = 打开界面
       右键 = 打开界面 / 打开数据目录 / 重启服务 / 退出
   * 关闭方式：右键托盘图标 → 退出。
     （直接关掉浏览器窗口不会退出服务，下次双击托盘图标又能打开界面。）
   * 详细功能见安装目录里的 使用说明.md。

五、卸载
   * 设置 → 应用 → 已安装的应用 → 搜索「无人机巡查数据地图」→ 卸载；
   * 或者直接运行安装目录里的 卸载.bat。
   * **卸载不会删除 Data\ 与 Project\** —— 你导入的数据和标记点都在里面，
     需要留存就自己备份，不需要就手动删掉这个目录。

六、系统要求
   Windows 10 / 11（64 位）。抽帧和 4K 转码用的是程序目录里自带的 ffmpeg，
   不需要另外安装；其余依赖都随包提供，不联网也能用（底图除外）。
