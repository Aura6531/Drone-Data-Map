# 安装向导最后一页 · 天地图 key 文案

> 这份是给安装包用的文案（Inno Setup 结束页的自定义页）。下面 A 段是页面上显示的正文，
> B 段是按钮/链接与校验提示，C 段是写入位置与实现要点。

---

## A. 页面正文（建议原样用）

**标题**：填一次天地图 key，底图和地名搜索就能用了

**正文**：

> 本程序的地图底图与「输入地名定位」由**天地图**提供，需要一串属于你自己的 key（tk）。
> 它是**免费**的，申请大约 2 分钟：

1. 打开天地图控制台：<https://console.tianditu.gov.cn/api/key>
2. 注册/登录 → 点**创建应用** → **应用类型选「浏览器端」** → 提交
3. 把生成的 **32 位** tk 复制下来，粘贴到下面的输入框

**小字说明**：

- 也可以**先跳过**：以后把 tk 粘贴到 `tianditu_key.txt`（就在程序目录里）也一样，**存盘即生效，不用重启**
- 一个 key 每天有调用额度，**多人共用一个 key 会互相消耗**；如果给多人用，建议各自申请
- 没有 key 也能用：底图会自动退回 OpenStreetMap，只是**地名搜索不可用**

**输入框**：`天地图 key（tk，32 位）`　[________________________________]

**按钮**：[ 打开申请页面 ] （用系统默认浏览器打开上面那个网址）

## B. 校验与提示

| 情况 | 提示 |
|---|---|
| 留空 | 允许继续（写提示：已跳过，之后可把 tk 放进程序目录的 `tianditu_key.txt`） |
| 长度不是 32 或含非十六进制字符 | `这看起来不是天地图的 tk（应为 32 位数字/字母）。可以留空跳过，之后在 tianditu_key.txt 里补。` 并**不阻止**继续 |
| 有首尾空格/换行 | 自动去掉（程序侧也会用 `utf-8-sig` 读取，能吃掉记事本写的 BOM） |

> 不做联网校验 —— 装完可能还没网，联网校验只会让人卡在这一页。

---

## C. 写入位置与实现要点（给打包脚本看）

- 安装时写入：`{app}\tianditu_key.txt`（`{app}` = 安装目录；数据都在程序目录内，这是既定方案）
- 用**无 BOM 的 UTF-8** 写；内容就是那 32 位 tk（不要加引号、不要加换行以外的字符）
- 程序侧读取逻辑（已实现，不用改）：`get_tianditu_key()` 依次看
  `环境变量 TIANDITU_KEY` → 常量 → `程序目录\Code\tianditu_key.txt`
  → 每次请求都重新读文件，所以**存盘即生效**
- 若用户跳过：**不要**创建空文件（空文件会让"未配置 key"的提示里少掉文件名线索）
