# 左栏三段化 与「已加载」面板

> 记录 2026-10-22 ~ 2026-10-24 这轮左栏改版：结构、数据从哪来、状态存哪、
> 以及踩过的坑。改这块之前先读这一页。

## 一、左栏现在长这样

```
┌─ 项目 ───────────────────────────────┐
│ 选择项目 [东莞地铁 ▾] ×    📌         │   ← 固定/收起在标题行右侧
│ [新建项目] [导入数据]                  │
├─ 数据文件 ────────────────── ⟳  ▾ ──┤   ← VS Code 风格文件树（懒加载）
│  📁 DJI_202609240950_001              │
│  📁 正射影像                           │
│  [导入选中]                            │
├────────── 拖动条（上下分配高度）────────┤
└─ 已加载 ────────────────────── ▾ ────┘
   ☑ 视频  (1/1)      −
   ☐ 照片  (0/1)      ＋
   ⊖ ☑ 位置点 (14/14)
      ⊖ ☑ 房子 (4)   ☑ 📍 东莞地铁-1 …
   ☐ 正射影像 (0/1)   ＋
   ☑ 覆盖图层 …
```

- **两块列表之间可拖动**分配高度（`#leftSplitter`，存 localStorage `uavmap.leftSplit`）
- 两张卡都能**随时收起**（`data-collapse`，收起只留标题行）
- 「已加载」的展开/收起状态存 localStorage `uavmap.collapsedGroups`

## 二、「已加载」的分组与数据来源

| 分组 | 数据来源 | 单条显隐 | 备注 |
|---|---|---|---|
| 视频 | `loadedTracks`（地图上的航迹） | 独立 `L.featureGroup` | 行尾带 `4K/1080p/热成像/360` 小标签 |
| 照片 | `/api/project/photos` 的 `groups` | `photoHidden`（按组下标） | 展开后按 **广角 / 变焦 / 360 全景** 三类 |
| 位置点 | `projectMarkers` | `ui.markers[name]` | **两层**：分类 → 具体点 |
| 正射影像 | `/api/ortho/list`（只取 `kind==='ortho'`） | 勾选 = 加载/撤图层 | 行内显示金字塔进度 |
| 覆盖图层 | `coverageItems`（`built` 的） | 勾选 = `coverageShow/Hide` | 只列已构建的架次 |
| 文字标注 | `project.labels` | — | 点名称飞过去 + 编辑条（字号/颜色/删除） |
| 多段线 / 多边形 | `project.vectors`（KML 导入） | 勾选 | 紫色虚线 / 半透明填充 |

规则（用户定的）：

- **空分类不显示**
- 组标题：总开关 + 名称 + `(显示/总数)`
- 每条：勾选框 + 图标 + 名称（点击 = 飞过去）+ `×`（移出）
- 折叠状态与显隐状态都记住，刷新后保持

## 三、状态存在哪（重要）

显隐/折叠这类"展示状态"要跨机器、跨浏览器一致 → **存进 `project.json`**：

```json
{
  "ui": {
    "videos":   {"DJI_..._V.MP4": true},
    "photos":   {},
    "markers":  {"东莞地铁-1": false},
    "ortho":    {},
    "coverage": {},
    "orthoHidden":    ["result.tif"],     // × 掉的，别再自动加载
    "coverageHidden": ["...srt"]
  }
}
```

- 写入：`POST /api/project/ui-state`（整份覆盖写）
- 读取：`GET /api/project/get` 返回的 `project.ui`
- **折叠状态**是个人偏好 → 存 localStorage（`uavmap.collapsedGroups`）

> ⚠️ 前端有 `window.__projectLoaded` 守卫：**没读到过项目时禁止整份覆盖写**，
> 否则一次空数组就能把用户已有的标注/矢量清掉（踩过）。

## 四、导入即上图（自动流程）

导入一个文件夹之后，`importScannedFolder()` 会依次：

1. `add-folder` 登记
2. `runAutoPipeline()`：检测字幕流 → 抽 SRT → 生成合并 GeoJSON → 加载到地图
3. `autoPrepareOrtho()`：项目里有正射影像就**建金字塔并加载**（几分钟，带进度）
4. `loadProjectPhotos()`：照片组立刻出现在「已加载」
5. 只有照片、没有航迹时**自动点亮照片图层**（否则用户以为没导入成功）

刷新页面时（项目是启动时恢复的、不会触发 `change`）：

- `autoLoadTracks()` 自动把 GeoJSON 加载进地图 → 「视频」组有内容、地图有轨迹线
- 有正射就顺带 `autoPrepareOrtho()`

## 五、相关接口（这轮新增/改动的）

| 接口 | 用途 |
|---|---|
| `GET /api/project/tree?name=&path=` | 文件树：列一层目录并分类（video/thermal/osv/pano/photo/kml/meta/other），**只允许项目文件夹内** |
| `POST /api/project/ui-state` | 存显隐状态（见上） |
| `POST /api/project/labels` | 文字标注整份保存 |
| `POST /api/project/vectors` | KML 矢量整份覆盖写 |
| `POST /api/project/kml` | 导入 .kml（解析 LineString/Polygon → GeoJSON） |
| `POST /api/project/delete-files` | 「同步删除磁盘文件」用；支持 `paths` 与 `relative_paths`，**只删项目文件夹内的媒体文件** |

## 六、踩过的坑（改这里之前务必看一眼）

1. **`onRemove:(async()=>{…})()` 写成了立即执行函数** —— 每次渲染面板就自动触发一次移除，
   用户看到"随便点什么都弹移除框"。回调不要带 `()`。
2. **HTML 没有 `Cache-Control`**，浏览器启发式缓存 → 改完代码用户还是旧页面。
   现在 `send_html()` 发 `no-store`，并留了 `window.__BUILD` 标记可自查。
3. **隐藏的旧筛选值会过滤掉全部 GeoJSON** → 自动加载拿不到文件，「视频」组空着。
   现在旧筛选块整块删掉了，`filteredGeoFiles()` 就是全部。
4. **全景照片被误判成广角**：它们叫「牛山1.JPG」、相机写 `WideCamera`。
   现在优先用成员上的 `panorama` 标记 / 宽高比 > 1.9。
5. **勾选分类后列表跳回顶部**：整块重建 DOM 导致滚动归零。
   现在 `renderLoadedPanel()` 渲染前后保存/还原 `scrollTop`。
6. **取消勾选后地图上的点还在**：`drawProjectMarkers()` 原本不看显隐状态，已修。
7. `trackGroup` 必须用 `L.featureGroup()`（`layerGroup` 没有 `getBounds`，
   外层 `getBounds()` 会退回去调 `getLatLng()` 而报错）。
