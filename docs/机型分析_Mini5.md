# 机型分析：DJI Mini 5（Mini 5 Pro）能不能直接放进我们的项目

> 结论先说：**今天不能直接用** ✗ —— 会卡在「遥测提取」这一步。
> 热成像相关不算缺陷：那本来就没有对象（见第 2 节）。
> 分析依据：上游格式目录（MIT，见 `docs/SRT格式与机型字段对照.md`）+ **我们自己的代码事实**（已在本文标注出处）。

---

## 一、一句话结论

| 问题 | 答案 |
|---|---|
| 视频能导入吗 | 大概能（编码是常规 HEVC，我们有解码与代理转码）—— 但要确认命名 |
| 遥测能取到吗 | **不能** ✗ —— Mini 5 Pro 的 MP4 **没有 SRT 字幕流**，遥测在 `djmd`/`dbgi` 定时元数据轨里；我们目前**只探测、不读取** |
| 地图/轨迹/跳转能用吗 | **不能** ✗ —— 轨迹就是从遥测来的，取不到就没有轨迹 |
| 热成像相关功能呢 | 天然不适用 ✓，且我们已经优雅降级（没有 `_T` 文件时「红外」按钮是 `hidden` 的） |
| 画面取点 / 视场框 | 取决于云台角字段是否存在 —— 上游目录**没有明确说** Format 3b 有云台角 ✗，需样片验证 |

## 二、逐项对照

| 我们的前提 | Mini 5 Pro | 依据 | 结论 |
|---|---|---|---|
| 从**字幕流**抽遥测 → SRT | **没有 SRT 字幕流** ✗（遥测在 MP4 的 `djmd`/`dbgi` 数据轨） | 上游 Format 3b 说明；我们代码里已专门识别 `djmd`/`dbgi` | **阻断项** ✗ |
| 经纬度 / 相对高度 | 有 ✓（Format 3b 带 `latitude`/`longitude`/`rel_alt`） | 上游字段表 | 只要打通读取就行 |
| 焦距（视场框宽窄） | **有** ✓（Format 3b 带 `focal_len`） | 上游字段表 | 比 Mini 3/4 Pro 好（那两个是 Format 1，没有焦距 ✗） |
| 云台俯仰 / 偏航 | **未知** ✗ | 上游只明确说 Format 3b 的 **Avata 360 变体**有 `gb_yaw`/`gb_pitch`；Format 3b 的键列表里没有云台角 | 需样片验证；缺了则视场框只能按航向近似、取点降级 |
| 热成像 `_T` | **没有** ✓（只有 T 后缀行业机型有） | 机型事实 | **不是缺陷** ✓：没有 T 文件时「红外」按钮不出现 |
| 可见光小画幅 `_S` | 未知 ✗ | — | 需确认；没有也不影响（单条可见光视频本身就能用） |
| 视频编码 / 帧率 | 4K/60 HEVC（消费级常见） | 待确认 | 我们已有 HEVC 解码 + H.264 代理转码，大概率没问题 |
| 文件命名 | 未知 ✗ | 我们按 `DJI_YYYYMMDDHHMMSS_NNNN_X` 组织，并用 `_V`/`_S`/`_T` 把同一条素材的多个流配对 | 若是 `DJI_0001.MP4` 这类序号命名，能导入但没有 `_V` 后缀，**流配对可能不认** ✗ → 需确认 |

## 三、要支持它，改造清单（按工作量排序）

1. **新增一条遥测读取通道**（核心）
   Mini 5 Pro 的遥测在 MP4 的 `djmd`/`dbgi` 定时元数据轨里。上游工具用 **ExifTool ≥ 13.52** 读；
   **我们目前既不打包也不调用 ExifTool** ✗（`Code/project_manager.py` 里搜不到 exiftool，只有对 `djmd`/`dbgi` 字样的**探测**）。
   两条路：
   - 引入 ExifTool（体积约 +10MB，注意其许可是 **Artistic/GPL**，与我们的分发方式要一起考虑）；
   - 自己解 `djmd`/`dbgi`（需要样本逆向，工作量大，但无新依赖）。
2. **把「有遥测」与「能提取」分开**
   现在探测只回答"有没有遥测"（`dji_telemetry` + `dji_telemetry_reason`），
   要再加"能不能读"，并在界面上说明："该机型遥测内嵌在 MP4 数据轨，需要额外工具"。
3. **命名与分组兼容**
   允许没有 `_V` 后缀的单条视频；`_S`/`_T` 当作可选（没有 `_T` 已有降级路径 ✓）。
4. **视场框 / 取点的降级标记**
   若云台角确实缺失：加 `has_gimbal=false`，界面写清"该机型无云台角，视场框为估算"，
   而不是算出一个看着对、其实错的结果。

## 四、我需要的样片（一段就够）

给我一段**原始 Mini 5 Pro 视频**（5~10 秒即可，**必须是原片，不要剪辑软件重导**），我用它实测四件事：

1. `ffprobe`：有没有字幕流？有没有 `djmd`/`dbgi`/data 数据轨？
2. 文件名实际长什么样（时间戳式还是 `DJI_0001` 序号式，尾缀是什么）；
3. 数据轨里有没有云台角（俯仰/偏航/横滚）与焦距；
4. 视频编码 / 分辨率 / 帧率（判断代理转码是否需要调整）。

拿不到样片之前，**不建议**对外声称"支持 Mini 5" —— 上游仓库自己也是这个规矩：
没有样片就不加解析。
