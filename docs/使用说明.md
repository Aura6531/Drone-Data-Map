# 无人机巡查数据地图 · 使用说明

> 一句话：把 DJI 无人机的一次次飞行，变成**地图上可点、可播的视频**。
> 点地图上的任意位置，就能跳到那一刻、那个位置拍的画面。

---

> **第一次安装被 Windows 拦了一下？** 这是 SmartScreen 对「没有代码签名」的程序的例行提示
> （弹窗写 Unknown publisher）。点「更多信息 → 仍要运行」，或右键 exe → 属性 → 勾「解除锁定」。
> 完整说明见分发包里的《安装说明（先看这个）.txt》。


## 一、装好之后

1. 双击安装程序 → 选安装目录（默认 `%LOCALAPPDATA%\无人机巡查数据地图`，**建议就用默认**，那个目录一定可写）
2. 安装向导最后一页会让你填 **天地图 key**（见下一节；也可以先跳过，之后再补）
3. 勾选「立即启动」→ 程序会常驻在**右下角托盘**，并自动打开操作界面

### 托盘图标怎么用

右下角那个小图标（飞机 + 目标点）右键：

| 菜单项 | 作用 |
|---|---|
| **打开界面** | 重新打开操作页面（不小心关掉了窗口时用） |
| **打开数据目录** | 直接打开程序目录，里面就是你的数据（见第七节） |
| **重启服务** | 界面打不开/卡住时用，会重启后台 |
| **退出** | **关闭程序**（关掉浏览器窗口不会退出程序，要在这里退） |

## 二、天地图 key（第一次必做）

底图瓦片和"输入地名定位"都走天地图，需要你自己申请一个**免费**的 key。

1. 打开 <https://lbs.tianditu.gov.cn/authorization/authorization.html>
2. 注册/登录 → **创建应用** → 应用类型选 **「浏览器端」** → 提交
3. 复制那串 **32 位**的 tk，粘贴到安装向导最后一页的输入框（或程序目录下的 `tianditu_key.txt`）→ 保存

- 改完 key **不用重启**，刷新页面即生效
- 一个 key 每天有调用额度，**多人共用一个 key 会互相消耗**；人多请各自申请
- 没填 key 也能用：底图会自动退到 OpenStreetMap，但地名搜索不可用

## 三、第一次用：从原始视频到出报告

### 1. 新建项目
左上「项目数据」→ **新建项目** → 起个名字（例如 `东莞2`）。项目名会成为标记点默认名的前缀。

### 2. 导入数据
「导入数据」→ 选**整个文件夹**或**挑几个文件**。
需要的是 DJI 的原始文件：**视频（MP4）+ 同名 SRT 字幕**（遥测数据在 SRT 里）。
导入后程序会自动跑：检测字幕 → 生成 SRT → 生成 GeoJSON（轨迹）。三个步骤的勾选状态会显示在「轨迹文件」卡片上。

### 3. 加载轨迹
「轨迹文件」里点某条的**加载**，或直接点**加载全部**。加载后地图上会出现这条飞行的轨迹线。

### 4. 看地图、点位置
- **点地图上的任意位置** → 视频跳到"拍到那里"的那一帧
- **点轨迹线上的点** → 视频跳到该点对应的时刻
- 地图上会实时显示**相机视场框**（画面在地面的覆盖范围）和无人机位置

> 视场框基于"平地假设"：俯角越大越准，接近平视时会明显偏。

### 5. 播放视频
4K 原片（H.265/HEVC）浏览器放不了，程序会**按需转码成片段**再播：第一次点会转几秒，之后有缓存，很快。
右侧/中间的播放窗里：**空格**＝播放/暂停，**Esc**＝关掉弹窗。

### 6. 在画面上右键取点（做标记点）
对着目标位置**右键** → 输入名字 → 确定。
- 程序会算出该像素对应的地面坐标，在地图上落一个点
- **同时记住你右键的那个画面位置** —— 生成 Word 报告时会在视频截图的同一位置叠一个**目标点标志**
- 名字不能与已有标记点重复（重复会提示你改）

### 7. 标记点列表（右栏「标记点」）
每行是 `[✓] 名称 纬度 经度 [×]`，按创建时间排序。点一行 → 地图定位到该点、视频跳到那一刻（**不自动播放**，按空格继续）。

表头四个按钮，都只作用于**勾选的点**（没勾会提示你）：

| 按钮 | 作用 |
|---|---|
| 删除 | 二次确认后删除标记点（**不动视频数据**） |
| 导出 KML | 生成 KML，可导入 Google Earth / 奥维等 |
| 复制经纬度 | 复制成「名称 + 纬度 + 经度」表格，可直接粘进 Excel |
| 生成 Word 报告 | 见下一节 |

### 8. 生成 Word 报告

弹窗里选三件事，然后「开始生成」：

- **图片尺寸**：`原分辨率`（4K 一帧原样嵌入，最清晰、文件大）/ `压缩至 320ppi`（约 2480px 宽，打印清晰、体积友好）
- **报告地图底图**：`卫星图`（推荐，红十字和飞机箭头更好认）/ `街道图` / `OpenStreetMap`
- （报告只包含**勾选的点**）

生成完会自动下载一个 Word（文件名形如 `标记点报告_东莞2_2026-10-06.docx`）。

**报告里有什么**：

- 首页：标题 + **可点击的目录** + 汇总表（序号/名称/纬度/经度/所在位置/视频文件/视频时间）
- 每个点一节，标题形如 `11. 东莞2-15`：
  - 字段表：名称、纬度（°N）、经度（°E）、所在位置（含镇/村级）、视频文件、视频时间
  - **图 1 视频截图**：该时刻的原片画面，**带目标点标志**（你右键取点的位置）
  - **图 2 地图截图**：目标点红十字 + 无人机图标 + 「无人机→目标点」注视虚线
- 图注居中；表格与图片同宽、左右对齐，方便打印装订

## 四、底图切换

地图卡片右上角「底图」下拉：**街道图（天地图）/ 卫星图（天地图影像）/ OpenStreetMap**。
报告里用哪个底图是**单独在报告弹窗里选**的，互不影响。

---

## 五、小技巧

- **标记点点一行**：地图 16 级定位 + 视频跳到那一帧（暂停状态）
- **空格**：播放/暂停；**Esc**：关闭当前弹窗
- 标记点列表在窗口窄时会自动缩成"只留名称"的多栏布局
- 底图切换后瓦片会缓存到本地，同样区域第二次打开更快

## 六、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 地图一片灰、没有底图 | key 没填/填错/过期，或这台电脑没有外网。检查程序目录下的 `tianditu_key.txt` |
| 「搜索地名」没反应 | 同上（天地图配额用完也会这样，隔天恢复或换 key） |
| 视频打不开、只有声音 | 转码中（等几秒）；或 `ffmpeg` 被删了 → 重装程序 |
| 「所在位置」显示 **未解析** | 天地图逆地理编码**只覆盖中国境内**，境外点解析不出来是正常的 |
| 项目打开后提示找不到文件 | 项目里记的是**当初导入时的路径**，换电脑/挪动文件夹后要重新「导入数据」选一次 |
| Windows 报"未知发布者/已阻止" | 安装包没有代码签名，属正常。右键 → 属性 → 解除锁定，或杀软里加信任 |
| 页面打不开 | 托盘图标右键 →「重启服务」；仍不行就「退出」后重新启动程序 |
| 想清空间 | `video_proxy\`（转码缓存，最多 4GB 自动清理）、`tile_cache\`（瓦片缓存）、`report_cache\`（报告产物）都可以直接删，程序会自动重建 |

## 七、数据放在哪 / 怎么备份

都在**程序目录**下（托盘菜单「打开数据目录」可直达）：

| 目录 | 内容 | 要不要备份 |
|---|---|---|
| `Data\` | 你导入的视频、SRT、生成的 GeoJSON | ✅ **要**（原始素材，最重要） |
| `Project\` | 每个项目一个文件夹，里面 `project.json` 存项目与**标记点** | ✅ **要** |
| `tianditu_key.txt` | 天地图 key | 可选 |
| `tile_cache\` `video_proxy\` `report_cache\` `Code\geocode_cache\` | 各种缓存与报告产物 | ❌ 可随时删 |

**换电脑**：把 `Data\` 和 `Project\` 一起拷到新机器的同名位置，再启动程序；
如果某个项目里的文件路径对不上，在该项目里重新「导入数据」指一次文件夹即可。

---

## 八、卸载

控制面板 →「程序和功能」→ 卸载。
**卸载不会删除 `Data\` 与 `Project\`**（你的数据保留）；要彻底清理就手动删掉程序目录。
